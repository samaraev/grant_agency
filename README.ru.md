# ГРАНТ — Дом изнутри

Сайт частного агентства недвижимости для **Москвы и Московской области**: портфолио домов по адресам, редакционные страницы для собственников и покупателей, каталог услуг, приём обращений с небольшой CRM, двуязычный интерфейс (RU/EN) и админ-раздел.

- Опубликованное приложение: <https://grant-home-inside.base44.app>
- English version of this document: [README.md](README.md)

> Публичный интерфейс по умолчанию русский, английский включается переключателем RU/EN в шапке.

---

## 1. Что это за продукт

Сайт построен вокруг **дома, а не объявления**. У каждого опубликованного объекта своя страница: факты, редакционное описание, заметки по квартирам, фотографии, видео и карта. Вместо автоматической оценки — разговор: единая форма обращения открывается в любом месте сайта, создаёт заявку, которая попадает в админ-раздел и на почту агентства.

На главной представлены три коллекции объектов:

| Коллекция | Значения `property_type` | Смысл |
| --- | --- | --- |
| Офисы и корпоративное жильё | `office`, `corporate_housing` | Особняки под представительства и резиденции для руководителей |
| Квартиры и пентхаусы | `apartment`, `penthouse` | Резиденции в историческом центре |
| Загородные дома и усадьбы | `dacha`, `estate` | Дома и усадьбы за городом |

Тип `residential` (жилой дом) тоже допустим и показывается в общем списке.

На публичной части видны только опубликованные дома (`is_published: true`).

### Поиск по адресу

`AddressSearch` сравнивает введённое с загруженными домами (адрес, улица, район, город). Совпадение открывает страницу дома, всё остальное уходит на `/search?q=…`. Оба исхода логируются (`address_search` с `matched: true/false`).

### Страница поиска

Фильтры хранятся в URL — любую выборку можно дать ссылкой, в том числе из коллекций на главной:

`?q=` полнотекст · `?district=` · `?street=` · `?group=offices|residences|estates` · `?deal=sale|rent`

Представления: **список** (карточки домов) и **карта**. Если ничего не нашлось, страница предлагает оставить адрес заявкой.

### Страница дома

Факты (год постройки, этажи, подъезды, число квартир, серия/тип, площадь, цена, тип сделки), редакционное описание, список особенностей, заметки по квартирам (`ApartmentNote`: тип планировки, диапазон площади, типичные вопросы, заметка о ликвидности), галерея, видео, карта Leaflet и кнопки решений, которые открывают форму обращения с уже подставленным домом и нужным типом запроса.

## 3. Приём обращений

Одна форма (`LeadForm`) в одном диалоге (`LeadDialog`), открывается из любого места через `LeadProvider` / `useLead()`: кнопка в шапке, кнопки в hero, страница дома, пустой результат поиска, страницы собственникам/покупателям/контактам.

Поля: тип обращения, адрес дома (с подсказками из базы), имя, телефон, удобный канал связи (звонок / Telegram / WhatsApp), комментарий, согласие на обработку данных.

Правила на сервере (`submitLead`):

- имя не короче 2 символов, телефон — 11 цифр, согласие обязательно (`true`);
- скрытое поле-ловушка: если заполнено, это бот — отвечаем «успехом» без записи;
- ограничение частоты: не более 5 обращений с одного IP за 10 минут (`429 rate_limited`);
- адрес сопоставляется с домом в базе и сохраняется как `building_id`;
- источник собирается из UTM-меток (хранятся в `sessionStorage` в рамках сессии), иначе referrer, иначе `direct`.

После отправки человек видит подтверждение и «что будет дальше», а агентство получает письмо на `SiteSettings.admin_email`.

Типы обращений: `owner_appraise`, `owner_sell`, `buyer_buy`, `buyer_check`, `general`.
Сайт **не** считает автоматическую оценку и говорит об этом в форме и в дисклеймере подвала.

## 4. Админ-раздел

`/admin` защищён: любой авторизованный пользователь открывает маршрут, но раздел показывается только при `role = "admin"`; остальные видят экран «нет доступа». Любая запись в базу дополнительно закрыта правилами доступа (только админ).

| Раздел | Возможности |
| --- | --- |
| `/admin` Дашборд | Обращения за 7 дней, всего, собственники и покупатели, воронка (новое → на связи → встреча → закрыто), содержательные разговоры, источники, типы запросов |
| `/admin/leads` Обращения | Фильтры по статусу/типу/источнику/дате, поиск по имени, телефону, адресу, смена статуса в строке, экспорт CSV, карточка с заметками и отметкой «содержательный разговор» |
| `/admin/buildings` Дома | Создание, редактирование, удаление, загрузка фото, выбор координат на карте, публикация, экспорт CSV, импорт CSV (обновляет по адресу, создаёт новые, отчитывается по created/updated/failed) |
| `/admin/services` Услуги | CRUD услуг, аудитория, статус (`active` / `planned`), порядок вывода |
| `/admin/team` Команда | CRUD участников, показываемых на странице «О нас» |
| `/admin/settings` Настройки | Телефон, почта, офис, ориентир, часы работы, Telegram, WhatsApp, VK, почта для уведомлений |
| `/admin/analytics` Аналитика | Топ поисковых адресов, поиски без совпадения, самые просматриваемые дома (за 30 дней) |

Фотографии из админки хранятся публично — открыть по ссылке может любой, — потому что они показываются на публичном сайте.

## 5. Модель данных

| Сущность | Назначение | Ключевые поля |
| --- | --- | --- |
| `Building` | База адресов | `address` (уникальный), `city`, `district`, `street`, `house_number`, `property_type`, `deal_type`, `price`, `area`, `year_built`, `series_or_type`, `floors`, `entrances`, `apartments_count`, `description`, `features[]`, `photos[]`, `videos[]`, `latitude`, `longitude`, `is_published`, `updated_at` |
| `Lead` | Входящие обращения | `type`, `building_id`, `address_text`, `name`, `phone`, `preferred_contact`, `message`, `status`, `source`, `utm_*`, `referrer`, `page_path`, `is_meaningful`, `admin_notes` |
| `Service` | Каталог услуг | `title`, `short_description`, `audience`, `status`, `sort_order` |
| `TeamMember` | Люди на странице «О нас» | `name`, `role`, `local_bio`, `photo_url`, `is_public` |
| `SiteSettings` | Контакты сайта | `phone`, `email`, `office_address`, `office_landmark`, `working_hours`, `telegram`, `whatsapp`, `vk`, `admin_email` |
| `Events` | Аналитика интерфейса | `event_name`, `path`, `session_id`, `building_id`, `search_query`, `matched`, `meta` |
| `ApartmentNote` | Редакционные заметки по домам | `building_id`, `layout_type`, `area_range`, `typical_issues`, `liquidity_note` |
| `User` | Встроенная сущность платформы | `role`: `admin` / `user` |

Правила доступа:

- **Публичное чтение**: `Building`, `Service`, `SiteSettings`, `ApartmentNote`, публичные `TeamMember`.
- **Создавать может любой**: `Lead` и `Events` (посетитель обычно не авторизован).
- **Чтение обращения**: его автор или админ. **Изменение и удаление**: только админ.
- **Чтение `Events`**: только админ.
- **Любая запись в каталог и настройки**: только админ.

## 6. Серверная функция

`base44/functions/submitLead` — единственная собственная серверная функция:

1. Читает и валидирует тело запроса (`type`, `name`, `phone`, `preferred_contact`, `message`, `address_text`, `building_id`, `consent`, `honeypot`, UTM).
2. Проверяет ловушку и лимит по IP.
3. Определяет `building_id` по идентификатору или точному совпадению адреса.
4. Создаёт запись `Lead` со статусом `new`.
5. Отправляет уведомление на `SiteSettings.admin_email` (сбой письма не отменяет сохранённое обращение).
6. Возвращает `{ ok: true, id }`, либо `400` (`name` / `phone` / `consent`), `429` (`rate_limited`), `500`.

## 8. Двуязычный интерфейс (RU / EN)

- Словари: `src/content/ru.js`, `src/content/en.js` — один файл на язык, одинаковые ключи.
- `src/lib/i18n.js` отдаёт живой объект `t`, `applyLanguage()`, `dateLocale()`, `LANGS`.
- `LanguageProvider` перемонтирует дерево при переключении; выбор хранится в `localStorage` (`grant_lang`), по умолчанию — русский.
- Переключатель — в шапке (`LanguageSwitcher`). Новый язык = один словарь + одна запись в `LANGS`.

## 9. SEO

- `src/lib/seo.js` задаёт title, description, robots, canonical, Open Graph, локаль и JSON-LD (`Organization` для сайта, данные дома на странице дома).
- `applySeo` убирает вставленные структурированные данные при размонтировании.
- Есть `public/sitemap.xml` и `public/robots.txt`; в `robots.txt` закрыты `/admin`, `/login`, `/register`, `/mfa`.
- Неизвестный маршрут отдаёт `PageNotFound` с мета-тегом `prerender-status-code: 404`; так же ведёт себя страница удалённого дома.

⚠️ **Домен**: `SITE_URL` в `src/lib/seo.js`, адреса в `public/sitemap.xml`, строка `Sitemap:` в `public/robots.txt` и canonical/OG в `index.html` всё ещё указывают на `https://rieltorcenter.ru`. Их нужно обновить, когда будет подключён финальный домен.

## 10. События и аналитика

`src/lib/track.js` — единая точка трекинга. Пишет в сущность `Events` с идентификатором сессии (`sessionStorage: grant_sid`) и JSON в `meta`; интерфейс трекинг не блокирует.

Используемые события: `page_view`, `address_search` (с `matched`), `building_view`, `cta_click`, `lead_submit`.

`/admin/analytics` читает последние 800 событий, оставляет 30 дней и показывает топ поисковых запросов, поиски без совпадения (список адресов, которые стоит добавить) и самые просматриваемые дома.

- Тёмная редакционная тема: фон `#1a2025`, поверхности `#1f272b` / `#263033`, светлая поверхность `#eee7dc`.
- Акценты: алый `#c8102e` (токен `--primary`, акцентные линии и выделения) и шампань `#c9b28c` (вторичный акцент, ссылки, надзаголовки).
- Шрифты: **Cormorant Garamond** для заголовков (`--font-heading`), **Inter** для текста (`--font-body`).
- Прямая геометрия (`--radius: 0.25rem`), тонкие линии, утилиты в `src/index.css`: `.rule`, `.pulse`, `.eyebrow`, `.link-underline`, `.fade-up`.
- Токены живут в `src/index.css` и подключены в `tailwind.config.js` — менять их нужно там, а не в компонентах.
- Все макеты адаптивны: проверяются на телефоне и на десктопе.

## 14. Локальный запуск

Репозиторий нужен, чтобы запускать и править приложение локально, а затем публиковать изменения через Base44. Любой пуш в репозиторий отражается в Base44 Builder.

### Что понадобится

1. Клонировать репозиторий по Git-адресу проекта.
2. Перейти в каталог проекта.
3. Установить зависимости: `npm install`.
4. Установить Base44 CLI: `npm install -g base44@latest`.
5. Установить [Deno](https://docs.deno.com/runtime/getting_started/installation/) — на нём работает локальный бэкенд Base44.

Полный набор команд — `base44 --help` (или [справочник CLI](https://docs.base44.com/developers/references/cli/commands/introduction)).

### Запуск

Три команды из корня проекта:

```bash
base44 login   # один раз на машину
base44 link    # один раз на клон
base44 dev     # локальный бэкенд + фронтенд
```

Откройте адрес фронтенда, который напечатает `base44 dev` (обычно `http://localhost:5173`).

Важно:

- **Каждому свежему клону нужен `base44 link`.** Он пишет `base44/.app.jsonc` (указатель на id приложения), который намеренно в .gitignore. Флаги для неинтерактивного запуска — в `base44 link --help`.
- **`base44 dev` сам запускает фронтенд** (через `site.serveCommand` в `base44/config.jsonc`) — не запускайте `npm run dev` отдельно: без бэкенда каждая `/api`-ручка падает, а рядом с `base44 dev` второй Vite молча займёт следующий порт.
- **Приложение должно быть опубликовано хотя бы раз**, иначе интерфейс под `base44 dev` не загрузится.
- Сущности, функции и авторизация работают локально — данные сущностей **только в памяти** и стираются при перезапуске `base44 dev`. Core-интеграции и OAuth-вход проксируются в развёрнутое приложение. Подробнее: [Local development overview](https://docs.base44.com/developers/backend/overview/local-dev/local-development-overview).

### Только фронтенд, бэкенд хостинга

```bash
base44 dev --remote
```

⚠️ В этом режиме записи идут в **prod-данные** приложения.

### Публикация изменений

После пуша в git публикуйте из дашборда:

```bash
base44 dashboard open
```

Репозиторий синхронизируется с Base44 через git, поэтому публикуйте из дашборда, а не через `base44 deploy` — CLI-деплой отправляет локальное дерево напрямую в обход синхронизации.

## 15. Известные ограничения и что дальше

- **Домен**: SEO-canonical, sitemap, robots и метаданные `index.html` всё ещё используют `https://rieltorcenter.ru`.
- **Контакты** (`SiteSettings`) — заготовки: телефон, почта и адрес офиса нужно подтвердить до запуска.
- **Политика конфиденциальности** — структурированный шаблон: нужны реквизиты компании и юридическая проверка.
- **Нет платежей и онлайн-записи**: сайт работает только через обращения.
- Фото и видео объектов хранятся ссылками; отдельной медиатеки, кроме загрузки фото в админке, нет.
- Автоматической оценки стоимости на странице дома нет намеренно.
